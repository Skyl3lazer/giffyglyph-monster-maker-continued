In this workspace there are three root folders. GMMC-v10 contains the project you are editing, called "Giffyglyph's Monster Maker Continued", or GMMC. It is the only folder in which you will ever change files, the others are only for reference. It is a module for a program called foundry. Foundry is running the system dnd5e. The GMMC module alters and extends the functionality of the dnd5e system running in Foundry. The second folder, v14, contains the code for the Foundry program. The third folder, dnd5e, contains the code for the dnd5e system. All three are written in javascript, with pieces being in other related languages such as json or css. Foundry is a program for running a virtual tabletop. Dnd5e is a roleplaying tabletop game called Dungeons and Dragons. GMMC alters the function of dnd5e to add a new type of "Scaling Monster," which have their own stat sheets and dynamic properties.
